# 秀儿直播助手 v1.6.8

## 📋 更新概览

本次更新包含以下改进：

### 问题修复

- 修复自动弹窗自动填充不稳定的问题：直播商品虚拟列表会从顶部完整扫描，避免多次点击自动填充时结果数量不一致。真实中控台 41 个商品已验证可完整读取。(`99cfaa5`)
- 加强浏览器路径校验：拒绝 `uninstall.exe`、安装器、更新器等非浏览器主程序，并在可用浏览器之间自动 fallback，降低用户误选路径导致启动失败的概率。(`c8eaa07`)
- 优化 auth-api 高可用和管理端性能路径：增加 MySQL 连接池参数、批量查询/批量操作、SSE 本地唤醒，以及更严格的 HA 健康检查和超时配置。(`dd8f207`)

### 构建与发布

- 加强发布前检查：更新 npm lockfile 中的安全补丁，兼容 `import.meta.env` 检查，补充 JWT secret 强度校验，并对已评估的 PyJWT disputed advisory 做可审计忽略。(`bf1352b`)

- **Windows**: 10 及以上
