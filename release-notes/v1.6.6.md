# 秀儿直播助手 v1.6.6

## 📋 更新概览

本次版本聚焦自动回复知识沉淀、商品 FAQ 工作台增强，以及鉴权与运行时稳定性加固。

### 新增功能

- 自动回复新增更安全的自动发送控制，降低误发风险
- 新增自动回复知识洞察能力，可查看知识命中、回复样本与效果信息
- 商品编辑弹窗支持查看最近命中的问题样本，并可一键采纳为 FAQ
- 商品工作台新增“仍有缺口 / 待复查 / 效果好”等知识筛选维度

### 问题修复

- 统一客户端与后端密码策略，减少修改密码、设置密码时的前后端校验不一致
- 收紧 auth 代理白名单与 secret 校验，降低敏感接口误暴露风险
- 加强应用退出、账号断开和浏览器会话清理，减少任务残留与状态漂移
- 修复新版 preload API 重构后测试环境兼容问题，确保任务控制回归链路稳定

### 优化调整

- 拆分 preload API，任务控制、系统能力和小号能力边界更清晰
- 自动回复预览、导出与知识样本联动更完整，便于长场次复盘
- 发版检查脚本补齐兼容常量错误，发版前校验更稳定

## 💻 系统要求

- **Windows**: 10 及以上
