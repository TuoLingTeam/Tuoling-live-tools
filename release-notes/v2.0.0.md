# 秀儿直播助手 v2.0.0

## 📋 更新概览

本次更新聚焦多账号直播控制稳定性、自动回复工作台体验、浏览器资源占用控制，以及后台审计写入性能。

### 直播控制与浏览器稳定性

- 加强直播状态判断：直播中需要更多连续离线信号才判定关播，`unknown` 状态不会再累计为离线，降低误停任务概率。(`a421122`)
- 优化断开连接收口：浏览器关闭异常时仍会清理会话状态并向界面发送最终断开态，减少“显示仍连接”的残留状态。(`a421122`)
- 新增无任务离线休眠和自动开播唤醒能力，离线空闲时可暂停检测并释放无头浏览器资源。(`17bf520`)
- 抖音/百应无头会话支持轻量 browserless runtime，评论监听和发评可在释放常驻浏览器后继续工作，降低多账号内存压力。(`ecce9a0`)
- 淘宝直播中控台连接更稳：增强直播间 ID 识别、跳转超时容错、引导遮罩关闭和核心控件等待。(`1d70bc6`)

### 自动回复与账号体验

- 新增自动回复工作台历史视图，支持查看当前场次和历史场次的评论、回复、命中来源与统计。(`0b40480`)
- 自动回复设置页改为更紧凑的分区布局，关键词回复支持 CSV/JSON/TXT 导入导出。(`c2192ad`)
- AI 回复设置增加知识库配置入口，便于集中维护自动回复参考材料。(`9b9c97f`)
- 自动回复队列会规范化观众昵称、过滤主播自身评论，并限制历史保留窗口，降低重复回复和历史膨胀风险。(`724fb70`)
- 添加直播账号时支持通过平台登录识别账号名并绑定平台，已绑定账号会锁定平台选择。(`abf45b1`, `27a18dc`)

### 后台与发布准备

- auth-api 管理端审计日志改为有界异步队列，避免高并发管理操作被同步审计写入拖慢。(`837b434`)
- 版本号推进到 `2.0.0`，同步 release notes 与发布规范材料。
