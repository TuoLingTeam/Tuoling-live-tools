# 秀儿直播助手 v1.6.5

## 📋 更新概览

本次版本聚焦发布前审计整改与直播控制链路收口。

### 问题修复

- 收紧本地认证存储与密钥管理，统一敏感文件权限与设备密钥策略（`528596a`）
- 本地评论监听 WebSocket 改为仅监听 `127.0.0.1`，并要求 token 鉴权（`528596a`）
- 统一浏览器关闭/页面崩溃断连语义，修正直播控制台状态恢复与提示（`bf144ec`）

### 优化调整

- 评论列表与回复预览默认只渲染最近窗口，支持按需加载更早数据，降低长时运行渲染压力（`528596a`）
- 替换关键平台链路中的固定等待和无限等待，降低卡死与空转风险（`528596a`）
- 认证调试日志默认降噪，仅在显式调试开关下输出详细链路（`528596a`）

### 测试相关

- 增加直播控制断连原因归一化与账号级断连信号回归测试（`bf144ec`）
- 更新评论监听运行态与配置同步测试，覆盖 WebSocket token 配置（`528596a`）

### 兼容性提醒

- 外部接入本地 WebSocket 的客户端需要更新连接方式：
  - 连接地址改为 `ws://127.0.0.1:<port>?token=<token>`
  - 或连接后首条消息发送 `{"type":"auth","token":"..."}`
  - 连接成功后服务端会先返回 `{"type":"auth-ok"}`
